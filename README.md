### About

Security Engineer focused on **Linux systems hardening**, **offensive security labs**, and **automation**.  
I design, break, and harden systems with a strong preference for Arch Linux and fully controllable environments.

Currently building practical tools and configurations used in personal infrastructure and security labs.

**Main focus areas:**
- System Hardening & Secure Desktop Environments
- Offensive Security / Red Team tooling & labs
- Detection Engineering & Automation
- Arch Linux infrastructure
